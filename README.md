# 🌱 마인드 버디 (Mind Buddy)

> 나만의 작은 마음 쉼터

**마인드 버디**는 일상 속에서 잠시 쉬어갈 수 있는 감정 케어 웹앱입니다.  
귀여운 동물 친구들과 대화하고, 힐링 게임을 즐기며, 마음을 편안하게 가꿔보세요.

## ✨ 주요 기능

### 💭 감정 표현 & 동물 친구
- 오늘의 기분을 이모지로 선택하면 동물 친구가 따뜻한 말을 건네줍니다
- 말투(다정/담백/유머)와 깊이(가볍게/깊게) 설정 가능
- 다양한 동물 친구들을 만나보세요

### 🎮 머리 비우기 게임
- **버블랩**: 뽁뽁이 터뜨리기
- **쓰담쓰담**: 동물 친구 쓰다듬기
- **얼음깨기**: 스트레스 해소하기

### 🧘 마음 챙김
- **숨 고르기**: 호흡 운동 가이드
- **어깨 내리기**: 긴장 풀기 운동
- **그라운딩**: 5-4-3-2-1 기법

### 📩 오늘 나에게 온 쪽지
- 하루에 한 번, 따뜻한 메시지를 받아보세요

### 📊 기록 & 도감
- 감정 기록 캘린더
- 만난 동물 친구 도감
